# Changelog

All notable changes to **meowMieru** (mierukop) are documented here.

## [1.3.3] — 2026-08-01
- **Исправлена регрессия 1.3.2**: статические Google-подсети снова включены по
  умолчанию (`settings.youtube_static_subnets`, отключить — значение `0`).
  Без них страница ролика уходила в туннель, а поток `googlevideo` — напрямую;
  YouTube привязывает ссылку на поток к IP запросившего, разные выходы дают 403
  и видео не играет. Имена хостов googlevideo уникальны на сессию, поэтому одной
  доменной маршрутизации недостаточно.
- Домены групп пишутся в dnsmasq drop-in **раньше** default-туннеля: dnsmasq
  учитывает первую `nftset`-директиву на домен, и широкий `russia_inside`
  перехватывал `youtube.com` — набор группы оставался пустым.

## [1.3.2] — 2026-08-01
Оптимизация по итогам аудита (CPU/RAM/скорость/стабильность):
- **Маршрутизация не «режет скорость»**: фильтр CDN-мегаблоков — второй эшелон
  `filter_megablocks` отбрасывает любые сети крупнее `/16` (порог
  `settings.subnet_min_prefix`, исключения — `lists/allow-big.lst`); в
  `exclude.lst` добавлены блоки Google Cloud. Раньше discord-список утаскивал в
  туннель Cloudflare `/12` и GCP `/11` — половина обычных сайтов ехала через VPN.
- **GOOGLE_SUBNETS выключены по умолчанию** (`settings.youtube_static_subnets=1`
  вернёт): весь фронтенд Google (поиск, карты, Play) больше не едет через
  туннель — YouTube маршрутизируется доменами через dnsmasq nftset.
  **Откачено в 1.3.3** — ломало воспроизведение видео.
- **Атомарное применение списков**: flush+add всех nft-наборов одной
  транзакцией `nft -f` — исчезло окно «пустых наборов» (утечка трафика мимо
  туннеля при каждом apply) и сотни форков `nft` на 2×A53.
- **conntrack-restore**: метка потока восстанавливается из ct mark первой же
  строкой цепочек — установленные соединения переживают обновление списков и не
  платят set-lookup на каждый пакет; `return` у групповых правил (default-набор
  больше не перетирает метку групп YouTube/Meta).
- **dnsmasq не рестартует зря**: drop-in переписывается во временный файл и
  dnsmasq перезапускается только при реальном изменении (раньше — на каждый
  apply, со сбросом DNS-кэша всей сети; при reload — дважды).
- **QUIC-фолбэк**: UDP/443 в туннель отклоняется (reject) — YouTube/браузеры
  мгновенно падают на HTTP/2-по-TCP вместо UDP-поверх-TCP с двойным congestion.
- **Watchdog**: пробит все туннели (default + группы), а не только default;
  self-heal срабатывает по реальному отсутствию состояния, а не по «< 10
  элементов» (ложные reapply каждые 5 минут на компактных конфигах).
- **RAM/CPU**: mieru групповых туннелей ограничен GOMEMLIMIT=32MiB (−32MiB
  потолка), логи mieru на WARNING (INFO писал каждое соединение в syslog);
  cron-задачи ставятся только при включённой фиче; `sample` — только append;
  `clients` — один awk-проход вместо форка на клиента; кэш `.lst` пишется во
  flash только при изменении.
- **LuCI**: один комбинированный `ui-status`-поллинг 5 с (статус+скорости за
  один форк), график пинга — раз в 60 с, «Клиенты» — раз в 30 с, поллинг
  останавливается в фоновых вкладках; внешние IP туннелей кэшируются 300 с
  (страница Обзор больше не делает N последовательных HTTPS-проб при открытии).
- self-update теперь доставляет `lists/exclude.lst` (роутеры, обновлявшиеся по
  цепочке, оставались со старым фильтром — причина «резки скорости» на местах).

## [1.3.1] — 2026-06-25
- **Node-aware**: на mesh-нодах (`/etc/meownet-role` = node) туннель не поднимается —
  интернет ноды идёт через main-роутер по batman-mesh. На обычных роутерах без роли —
  поведение без изменений.
- **Интеграция в прошивку**: модуль (бинарники mieru/hev + CLI + LuCI) встроен в
  overlay сборки вместо podkop/sing-box; first-boot uci-default настраивает сервер из
  provisioned mieru-конфига.

## [1.3.0] — 2026-06-25
- **Многостраничный интерфейс** — вместо одной длинной страницы пять вкладок в
  нативном стиле LuCI: **Обзор** (статус, туннели, трафик, график пинга, качество),
  **Серверы** (выбор активного, таблица серверов, пинг/лучший, подписка),
  **Маршрутизация** (списки, группы, свои правила), **Диагностика** (проверка обхода,
  клиенты), **Настройки** (поведение, автоматизация, сеть, версия/обновление).
- Общий код вынесен в `resources/mierukop/lib.js`; установщик теперь сам ставит все
  файлы LuCI-приложения (раньше требовалась ручная выкладка).

## [1.2.1] — 2026-06-25
First tagged GitHub release. No code changes vs 1.2.0 — published so the built-in
update checker (`mierukop update-check` / «Проверить обновление») has a release to
detect and install.

## [1.2.0] — 2026-06-25
- **Клиенты** — панель устройств LAN: активные соединения, трафик и сколько из них
  идёт через туннель (детект через `ct mark` в nftables).
- **Авто-выбор лучшего сервера** — кнопка «Выбрать лучший сейчас» + тумблер
  авто-режима (cron каждые 15 мин выбирает сервер с наименьшим пингом).
- **Авто-обновление подписки** — URL подписки запоминается при импорте; ежесуточный
  refetch подтягивает новые серверы и сменившиеся IP.
- **Проверка обхода** — по каждому туннелю показывает внешний IP, страну и реально ли
  отвечают YouTube / Telegram / Discord.
- **Карточки туннелей** — статус default + каждой группы с живым внешним IP.
- **График задержки** — спарклайн истории пинга активного сервера.

## [1.1.0] — 2026-06-25
- **Самообновление модуля** — отображение версии, `update-check` (через туннель,
  т.к. raw.githubusercontent заблокирован в РФ), `self-update` одной кнопкой и
  авто-обновление по cron (раз в неделю, по тумблеру).
- Цветовая индикация пинга (зелёный/жёлтый/красный) в таблице серверов и в панели
  качества; бейдж состояния подключения в шапке.

## [1.0.0]
- Первый релиз: селективная маршрутизация через mieru SOCKS5 (podkop-style),
  per-group туннели, подписки в формате Clash, watchdog, kill-switch, LuCI-приложение.
